# CODSOFT_Data_Analysis_Task1
# Titanic Dataset Cleaning and Preprocessing

## Objective

The objective of this task is to clean and preprocess the Titanic dataset by handling missing values, removing duplicates, and preparing the dataset for further analysis.

## Tools Used

* Python
* Pandas
* VS Code

## Steps Performed

1. Loaded the Titanic dataset.
2. Checked for missing values.
3. Filled missing values where necessary.
4. Removed duplicate records.
5. Saved the cleaned dataset as `cleaned_titanic.csv`.

## Output

A cleaned Titanic dataset ready for analysis and machine learning tasks.
